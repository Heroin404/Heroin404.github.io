# 🖼️ Random Masterworks (RU)

**Random Masterworks** — это веб-приложение (PWA) с бесконечной вертикальной прокруткой, которое позволяет открывать для себя мировые шедевры классического искусства в формате современного медиа-фида (подобно TikTok или Reels).

## ✨ Особенности
* **Бесконечная лента:** Плавный вертикальный скролл с мгновенной подгрузкой картин.
* **Агрегатор мировых музеев:** Изображения в статусе Public Domain (CC0) случайным образом подтягиваются из открытых баз данных крупнейших мировых коллекций.
* **Высокое разрешение:** Возможность легально скачивать оригиналы картин без водяных знаков в один клик.
* **Автоматический перевод:** Метаданные (название, автор, материалы) автоматически переводятся на язык пользователя.
* **PWA (Progressive Web App):** Приложение можно установить на экран "Домой" смартфона (iOS/Android) для полноэкранного использования без интерфейса браузера.

## 🎯 Идеально подходит для:
* **Эстетического погружения:** Визуализации атмосферы европейской литературы XIX века (полотна, идеально перекликающиеся с мирами Эмиля Золя, Виктора Гюго и Марселя Пруста).
* **Коллекционеров и историков:** Удобного поиска референсов антикварной живописи и декоративного искусства (например, изучения техник мазка или оригинальных багетов эпохи Второй французской империи).
* **Дизайнеров и художников:** Быстрого доступа к бесплатным высококачественным текстурам и классическим референсам (CC0).

## 🏛️ Интегрированные источники (API)
* The Metropolitan Museum of Art (The Met)
* Harvard Art Museums
* The Cleveland Museum of Art
* Victoria and Albert Museum (V&A)

## 🛠️ Технологии
* Vanilla HTML / CSS / JavaScript
* DOM Intersection Observer (для ленивой загрузки)
* CSS Scroll Snap
* REST API + `Promise.all` для параллельной загрузки из разных источников

## 🚀 Установка и запуск
Проект не требует сборки. Достаточно склонировать репозиторий и открыть `index.html` в любом современном браузере или разместить файлы на GitHub Pages.
# 🖼️ Random Masterworks (ENG)

**Random Masterworks** is a Progressive Web App (PWA) that offers an infinite, vertically scrolling feed of classical art masterpieces, merging the UX of modern social media (like TikTok or Reels) with the rich heritage of global museum collections.

## ✨ Features
* **Infinite Feed:** Smooth, snap-scrolling vertical feed with seamless lazy loading.
* **Global Museum Aggregator:** Randomly fetches Public Domain (CC0) artworks from the open APIs of world-renowned museums.
* **High-Res Downloads:** One-click downloads of original, unwatermarked, high-resolution masterpieces.
* **Auto-Translation:** Artwork metadata (title, artist, medium) is automatically translated into the user's preferred language.
* **PWA Ready:** Can be installed directly to the home screen of any iOS/Android device for a native, fullscreen experience.

## 🎯 Perfect For:
* **Aesthetic Immersion:** Visualizing the atmosphere of 19th-century European literature (discovering paintings that echo the worlds of Émile Zola, Victor Hugo, and Marcel Proust).
* **Collectors & Art Historians:** Gathering references for antique paintings and decorative arts from the 17th to early 20th centuries (e.g., studying original framing and aesthetics of the Second French Empire).
* **Designers & Artists:** Getting instant access to high-quality, copyright-free (CC0) textures, references, and inspirations.

## 🏛️ Integrated APIs
* The Metropolitan Museum of Art (The Met)
* Harvard Art Museums
* The Cleveland Museum of Art
* Victoria and Albert Museum (V&A)

## 🛠️ Tech Stack
* Vanilla HTML / CSS / JavaScript
* DOM Intersection Observer (for infinite scrolling)
* CSS Scroll Snap
* REST API + `Promise.all` for parallel fetching from multiple sources

## 🚀 Usage
No build tools required. Simply clone the repository and open `index.html` in any modern browser, or host the files directly on GitHub Pages.
